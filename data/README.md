# Data

Download [drugsCom_raw.zip](https://archive.ics.uci.edu/ml/machine-learning-databases/00462/drugsCom_raw.zip) (43 MB) from UCI and unzip it here. You should get `drugsComTrain_raw.tsv` and `drugsComTest_raw.tsv`.

The files are not committed: together they are over 100 MB, which GitHub rejects.
